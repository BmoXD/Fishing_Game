# 🎣 Box Cat Goes Fishing

A small fishing game inspired by **Webfishing**.

---

## About the Project
I really enjoyed playing Webfishing, its mechanics and design deeply intrigued me.  
So I challenged myself to recreate it from scratch as a learning project and as a final assignment for my Unity course in University.

While building this clone, I explored and implemented:

- Inventory system  
- Minigame logic (fish catching mechanic)  
- Player controller scripting  
- UI systems  
- Shader creation  

I spent hours studying the original game, idling, observing tiny details, and figuring out how each feature might work behind the scenes. This project became both a technical challenge and a deep dive into game design analysis.
